# 剧本正文模板

按统一场记体输出完整场次。用户明确指定其他格式或要求照原稿格式时，按其要求执行。保留原有画幅、叙事人称和编号体系，只调整新正文的排版。只交正文时，从正文开始。

## 标签和用途

| 标签 | 写什么 |
| --- | --- |
| 【场景头】 | 每场一行，依次写编号、日/夜、内景/外景/内外景、具体地点，各项以全角竖线隔开。 |
| 【画面】 | 观众要看见的现场状态、重要道具、环境或反差。 |
| 【动作】 | 人物做了什么、怎样反应、现场如何变化。关键动作放在它影响的对白前后。 |
| 【对话】 | 每位说话人单独起行，使用 `【对话】人物名：“台词。”`。 |
| 【音效】 | 对现场、节奏或情绪有作用的声音，有明确用途时写。 |

每场先写【场景头】，其余标签按实际发生顺序穿插，按需使用，可在一场里重复出现。画面交代可见状态，动作写正在发生的变化。同一信息写一次。旁白、内心独白、字幕和黑屏按项目既有约定或本次要求使用。

## 场和集

- 按场写时用项目的场号，例如第018场。续写从采用稿最后一场接号。
- 一集有多场时，用集标题组织本集各场，场景头标场号。原项目已有集场双定位时，保留两级编号。
- 一集确实只有一场，且原项目以集号代场号时，场景头沿用集号，例如第010集。
- 沿用原稿编号位数与连续规则。场数和集数分别按用户要求计数。

## 示例

```text
【场景头】第018场｜夜｜外景｜镇西·铮诚汽修院

【画面】一辆货车停在院门口，双闪照着门槛。

【音效】货车打火两下，发动机没起来。

【动作】沈铮从维修棚快步走出来，抬手示意司机停下。

【对话】沈铮：“先别打了，我来看看。”
```
