# 拉片工作流

用户要求从视频还原逐集、逐场剧本或逐镜拉片时，先按 [video-breakdown.md](video-breakdown.md) 提取与核对原片内容。本文件用于后续剧情和手法分析，不能用分析概括代替用户请求的拆解正文。

## 读取与分段

先按 [project-records.md](project-records.md) 定位素材索引、参考原文及已有分析；分析目标稿时定位项目索引及对应版本。核对来源版本和各项覆盖范围。已有有效成果直接复用，只分析缺失、追加或受修改影响的部分。按实际集号、场号切分；没有显式场号时按连续时空与完整行动识别场次，保留与原文段落或真实时间码的对应。不因每组需要五场而改变原场界。

覆盖用户指定的全部范围。长材料分段读取，先保留事实再归纳跨段关系；注明尚未覆盖范围，不把局部分析写成全剧结论。仅有局部原稿时，只分析已提供内容。

有多部参考时沿用同一分析流程，逐来源登记和保存，不因名称、场号或桥段相似就合并事实。可跨剧比较期待、冲突机制、人物选择及表现手法，但注明各自证据、适用前提和区别，供共享的 case-alignment.md 选取，不另建重复的原剧分析。执行中按 SKILL.md 简报实际读过的来源、范围和复用/补缺进度，明确未读部分。

区分原文事实、分析判断与尚未确认。观众感知使用“预期/可能/根据该行动推断”等措辞，给出剧情依据，不伪造观众反馈或留存率。

## 人物、设定与主线

提取主要人物身份关系、长期诉求、阶段目标、性格在行动中的表现、施压/应对习惯、底线弱点及依据场次。年龄、服饰和背景缺失时保留缺失，不沿用其他项目设定。

对主要角色，把性格还原为“什么处境触发—惯常怎样选择、说话和行动—造成什么后果”，注明原场对白或动作。行为习惯包含处理冲突、求助、掩饰、拒绝及对不同关系的态度，按材料实际呈现提取。只有一次发火不能直接认定为暴躁；反复出现或关键选择能支持稳定特征，证据不足时标为初步判断。不能只写“善良、强势、聪明”等标签，也不能替原作补造习惯。

明确回答人设是否立住：哪些特征已经从行动中可辨认，哪些仅由旁人评价、尚未写出来，哪里前后矛盾。记录稳定性格与表达习惯，另记当前情绪、应对策略和成长变化。变化须定位触发事件、选择过程与后果；相似处境下反应不同，核对关系、信息、代价或成长是否足以解释。把“人物原有缺点”与“写作造成的人设漂移”分开。

提取核心设定：主角凭什么立足、为何受制、对手凭什么施压、双方争夺什么、观众最初得到什么故事承诺。按“主角目标—主要阻力—应对路径—当前结果”写主线，分开已发生走向与未来规划。

在主线总览中讲清核心总线、中心与表现手法的关系：
- 核心总线：谁持续想得到或守住什么，什么主要矛盾反复阻碍，阶段事件如何改变这场争夺或关系。不能只写题材名或逐场流水账。
- 中心问题：全剧反复让人物面对的选择、关系或价值冲突是什么，正文怎样通过选择及后果呈现；有歧义时保留多种有依据的解读，不硬编唯一主题。
- 主导表现手法：如关系对照、信息差、日常细节累积或行动反转，实际怎样服务中心和情绪，附代表场次。区分贯穿全剧的手法与局部技巧，不只列术语。
- 阶段与支线联系：当前阶段推进总线哪一步，支线怎样改变主线人物、关系、选择或代价。只读局部时标明暂定范围；结局方向仅在原文已呈现或用户明确规划时记录。

## 每五场概括

从指定分析范围第一场起每五场一组，已有项目沿用原分组边界。尾组不足五场如实记录，不补场。增量分析先补齐上一尾组再另起组；局部补分析保留原场号。

每组单独保存为五场文件，主线另存总览，路径与模板见 project-records.md。文件登记来源版本、实际范围、原文位置和完成状态；索引按场号、人物、事件和剧情阶段定位。只读取标准目录内已迁移的资料，不维护旧聚合目录入口。每完成一批就保存并更新索引，中断后从成功保存点继续；概括完成不代表人物与手法分析也已完成。

| 栏目 | 具体内容 |
| --- | --- |
| 范围及来源 | 集/场号、原文位置或真实时间段 |
| 因果概括 | 谁为了什么行动，遇到什么，怎样应对，导致什么结果 |
| 核心交锋 | 每轮阻力与反击怎样不同，哪一步改变局面 |
| 人物动机与行为 | 阶段目标、稳定特征怎样体现在选择与表达中；有无变化及依据 |
| 总线联系 | 本组推进哪项核心争夺或关系，怎样体现中心，使用什么具体手法 |
| 情绪过程 | 观众替谁、因何产生何种预期感受，怎样积累、转变或兑现；人物反应另记 |
| 观众感知 | 此时已知、期待或可能误信的内容及剧情依据 |
| 推进与交接 | 组末比组初改变什么，下一组为何发生 |
| 伏笔和悬念 | 新提出、已回应、未兑现，附原场号 |

保留改变因果的金额、条件、关系、证据来源与持有人。概括具体事件，避免只写“冲突升级、爽点密集、情绪爆发”。跨组交锋在相邻组标明接续关系。

## 推进、情绪与表现手法

仅在本次分析需要相应题材写法时，按 SKILL.md 的题材入口读取对应独立指导，不默认加载其他题材。结论仍回到实际原场，不把指导示例当作原作事实。

先说明已读范围的主导观众感受与变化，再落实到场次：观众在意谁、知道什么、盼望或担心什么，哪个行动触发感受，何处加强、缓和、反转或留下余味。例如人物得意可能让观众愤怒，人物害怕可能让观众紧张，也可能因观众提前知情而产生喜感；判断依据是具体处境和信息安排。喜怒哀乐、紧张、好奇、温暖等不设固定配额或固定曲线，悲伤和开放悬念也可以是有效落点。

建立逐场简短记录：场号、进入局面、目标与行动、对方回应、局面变化、观众预期情绪、期待及触发依据、结尾交接。该表服务复刻对照，不把每场强行改成独立反转。

从实际片段提取：
- 冲突怎样触发，几轮行动与回应后改变，胜利怎样带来新后果。
- 压力、希望、受阻、释放由哪些行动承载，关键兑现的位置与方式。
- 对白怎样逼问、谈条件、拒绝、试探和反击，句式长短与口语特点。
- 动作、道具与旁人反应怎样确认选择、传递信息、证明输赢。
- 信息由谁知道，证据何时出现，悬念怎样在后续回应。
- 场景如何进入退出；视频可见时再记停顿、视听剪辑，文本未提供则不臆测。

每条手法写“原场怎么做—有什么作用—在本项目何时适用”，附原场号和能回读的关键动作、对白或结果。涉及交锋时标出哪一轮改变了局面，观众凭什么看出变化，供复刻与续写逐场核对。不要把具体道具或桥段写成所有故事的公式。复刻是否保留源剧独特顺序与设定服从用户要求，不自行换题材。

为后续写作保留少量可直接回读的完整事件片段定位，标明剧情阶段，说明行动与回应的顺序、决定输赢的一步及结果怎样确认。跨五场文件的事件注明完整范围与关联位置，供复刻、续写按 [case-alignment.md](case-alignment.md) 读取对应阶段。分开值得学习的手法与需要改进的问题；不要只给“节奏紧凑、动作丰富”等无法对应原场的评价。续写据此选择适用标杆，承接最近事实，同时避免重复已识别的弱点。

## 交付

按 project-records.md 保存本次实际产生的人物设定、主线总览、五场文件与推进表现手法，核对文件可读、来源版本和索引覆盖一致；采用稿再维护当前状态。只拉片时不要续写或复刻。用户只要某项时仅提取并保存该项所需成果，不强制扩为全套分析。已有分析时补缺更新，不重建互相矛盾的事实。
