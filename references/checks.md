# 交付前检查

只检查当前任务相关项，针对性修正，不无限重写合格内容。

## 执行过程可见

- 已按 SKILL.md 的“执行过程可见”规则在执行中简报真实已读文件与范围、资料复用或补缺、多案例贡献、实际检查与修正、保存结果，未把计划当成已完成。
- 用户只要正文时，最终正文可不附长表，不作为全程静默的理由。只有明确要求全程不说明时才省略进度；不输出冗长临时构思。

## 资料复用与保存

- 已按 [project-records.md](project-records.md) 读取项目索引，核实本次来源版本、资料身份与各类实际覆盖，复用有效成果，只补缺或更新变化范围。
- 五场概括分文件，主线总览独立；场号、尾组实际范围、相邻组交接及索引引用一致，按人物、事件和剧情阶段可定位。旧聚合文件拆分后没有两个互相冲突的当前维护入口。
- 原稿修改已核对后续因果、人物知情、证据和伏笔的连带影响；未核实资料没有冒充有效结论。
- 本批分析、新稿及可复用对应已保存且真实可读，索引记录正确版本、覆盖、完成状态与下次起点；未完成项没有登记完成。正文和案例原文仍可按记录定位，临时附件缺口如实注明。
- 待采用稿及其对应没有覆盖采用稿资料。用户明确不写文件时按要求处理；文件或索引保存失败时准确说明缺口，不冒称全部已保存。

## 拉片

- 结论来自实际读取范围，姓名、金额、关系和证据定位可回查。
- 已明确人设哪些立住、哪些证据不足；稳定性格、行为与表达习惯有原场依据，临时情绪、成长与疑似漂移分开，单次反应未擅自上升为固定人设。
- 五场概括覆盖连续、尾组如实，跨组因果有交接。
- 提取用户范围内的核心设定、核心总线与中心、阶段推进及表现手法，说明它们如何相连；观众替谁、因何产生何种预期情绪及其变化有依据，未把人物表情等同于观众感受。
- 分清事实、判断、未来规划与缺失，不伪造时长、观众反馈或未发生后文。

## 复刻

- 指定原场的戏剧作用、结构顺序、节奏、推进层次和钩子落点都有实际新场对应，获准增删改动落实到场次。
- 新人物、关系与设定能支撑对应交锋，用户指定的保留项及目标稿已采用事实得到遵守。
- 交锋轮次、信息揭晓顺序、信息差、情绪积累与爽点兑现位置未被无意省略、提前或改变；具体证据与反击按新事件核对。
- 动作反应支撑结果，完整正文与口语对白，无行业讲解挤占交锋。
- 新稿与采用稿身份清楚，未把参考后文当已发生事实。
- 按参考与新稿的实际交锋核对，不只检查事件主题相同；缺失的应对、受阻、关键行动或结果确认已补回。
- 遮住姓名、职业和道具名称后，检查是否仍只是原事件换名、原对白换词；新场的起因、筹码、应对与后果须由新处境支撑。发现照搬时重写具体事件或表达，同时守住对应结构；用户明确指定的保留项不强制改写。
- 按 [case-alignment.md](case-alignment.md) 读过本批对应原场的完整事件并做写前校准、写后纠偏；一比一范围的附加案例未覆盖指定参考的保留要求。明确多剧或分段指定参考时，每段来源及重构范围清楚，没有声称与所有来源均一比一。

## 续写

- 真正读过首十场、最近十场及中间概括；不足、重叠、跨窗口交锋正确处理，关键伏笔按需回读。
- 开场承接上一场行动、时间地点、知情与证据状态。
- 行为动机有据，选择产生后果，冲突改变局面，避免重复和靠新增强事件推进。
- 旧期待适时兑现，新期待从局面发展。
- 场/集数量和编号正确，承接原稿叙事人称与细节密度，结尾符合要求。
- 状态更新来自已采用正文，未采用新稿不覆盖状态。
- 有对标案例时读过对应阶段的完整片段，跨五场文件的事件已补齐；匹配依据是已核实映射或剧情阶段，案例未替代采用稿首尾正文和中间概括，未把案例原剧事实冒充采用稿已发生事实。
- 已结合案例同期片段检查实际新稿的交锋、动作对白、情绪兑现与结果确认，具体偏离已在本批修正并复核，保存对应与校准结果。

## 网文改编

- 标明已读原著范围。主角核心诉求、关键事件及兑现仍有原著或用户要求作依据，新增或重排可区分。
- 删并后仍看得出角色为什么行动，关键证据从哪来，必要的知情顺序和情绪铺垫仍成立。
- 集界由局面变化或用户指定的卡点决定。章段合并、拆分或前移后，前一集的行动确实引出后一集。
- 写正文时，小说内心、设定和长叙述已转换为能呈现的选择、动作、对白或后果，关键交锋没有被概括跳过。
- 未授权重构原著时，多案例贡献限定于指定写法维度，前置条件能由原著支撑；明确授权剧情融合时，新增或重构符合授权且前提与因果成立，标明新设计，没有用其他剧的人物或事件冒充原著事实。

## 对标仿写

- 指定手法有参考场次或段落依据。新稿的施压、受阻、反制与兑现通过新故事的具体事件实现。
- 关键事件由新人物的目标、关系和行业条件引起。若遮住人名后只是给原剧人物和事件换名，回到新设定重构交锋过程和结果。
- 新稿的人名、标志性道具、辨识度高的对白和开场动作具有自身来源。情绪回报能从新稿正文看见。

## 多来源的分工、重构与校准

当前任务涉及多个来源时，按 [case-alignment.md](case-alignment.md) 的同一套共享案例规则检查，不增加独立任务模式：

- 各案例身份、版本、分析与五场文件独立，同一来源只维护一份源分析；索引约定和批次对应只引用源分析与原文，不复制维护另一套数据。实际使用的每项贡献有真实完整事件依据，没有只靠概括冒称读过原文。
- 索引“参考分工与融合约定”说明各剧在本任务指定维度的贡献和取舍；普通多案例校准没有被擅自扩大为剧情素材融合，也没有强制来源配额或每场全用。
- 目标人物、设定、主角目标与情绪承诺统一；各来源素材已重构成连续因果，前置条件、知情、证据及持有人与当前正文相容，没有并排拼接冲突设定。
- 重复冲突、重复消息和重复兑现已取舍；按各项实际贡献检查新稿的行动、反制与结果，去掉来源标签后通读仍是一个故事。
- 长期借用范围、分工和取舍保存在索引“参考分工与融合约定”，逐批多对多映射合记一份写作对应文件，记录独立来源、目标稿版本、实际落实和纠偏，可从索引定位；待采用融合稿没有覆盖当前采用稿事实。

## 题材写法检查

仅对本次实际采用的题材指导执行其写后回查，按 SKILL.md 的题材入口定位对应独立文件。不默认读取或执行其他题材的规则。

## 正文格式检查

交付完整场次时，按 script-format.md 核对场景头、标签用途、对白分行及场/集编号。用户指定其他格式时按其要求核对。仅替换指定段落时检查替换内容能否直接接回原文。

## 正文复核

用下表逐场扫一遍新稿。关键交锋按轮核对，重点看连续谈判、专业解释、胜负改变和批末交接。发现问题时，记下新场号、出问题的对白或动作、缺少的作用及改法。涉及拉片手法时一并标来源与原场号。执行中简报实际检查、具体修正和剩余缺口，最终正文可不附长表；可复用的对应、校准结果与缺口仍随该稿保存，临时构思不必保留。依原场与新场定位判断，不设置通用字数、动作比例、反转频次或效果分数。

| 检查点 | 在正文里寻找什么 | 发现缺漏时怎样修改 |
| --- | --- | --- |
| 事实与承接 | 台词依赖的数字、承诺、先前说法和材料内容，是否在已读原稿或新稿中真实出现 | 回查所指场次，改掉无依据的引用或补足必要铺垫；不把未写出的构思当成前文 |
| 人设持续成立 | 主要角色关键选择、说话与做事方式是否承接目标稿已建立的人设；反常行为是否有处境、信息或成长过程支撑 | 对照目标稿人物依据与新场，修正为凑情节而改变的行为，或写足合理转变过程；不靠重写档案掩盖漂移。避免为表现习惯反复塞同一句口头禅或动作；复刻新人物不自动继承原角色性格，用户明确保留的人设按要求核对 |
| 核心总线与中心 | 本批事件和支线怎样改变核心争夺、关系或选择，中心是否通过实际后果呈现 | 修正无联系的新增冲突或接回必要因果；立人、日常与情感段按实际作用保留，不把主题改成角色说教 |
| 表现手法与观众情绪 | 具体对照、信息安排、细节或行动怎样服务中心；观众替谁、因何产生何种感受，变化发生在哪个动作或结果 | 补足触发、积累、转变或落点，修正无铺垫煽情和一味加压；不拿人物喊哭喊笑或分析中的情绪标签替代正文，也不声称真实观众效果已验证 |
| 分析落实 | 按来源、原场号和新场号核对。原场怎么施压、如何受阻、哪一步改变局面、谁或什么结果确认变化，新稿用哪些事件、对白和动作实现对应作用 | 补写缺失的步骤。一比一复刻守住结构顺序、推进层次和兑现点，具体实现来自新人物与处境；融合范围按明确的取舍重构。续写与仿写用当前人物和处境实现选定的戏剧作用。改编检查原著铺垫、行动与结果在新稿中的承接 |
| 场次与交锋推进 | 每场是否增加必要的信息、情绪积累或局面变化。关键交锋的下一轮是否改变条件、筹码、证据、立场或可选行动 | 删减换人复述或换句施压，或补出让人物改变做法的行动及其后果。过渡、劳动和反应场按其实际作用检查，保持指定场数 |
| 有效动作 | 动作是否影响交锋、证据、任务进展或人物选择 | 删除重复的装饰反应；按情节补写真正的行动，不硬塞职业表演 |
| 对手退让 | 对手原目标、筹码、尝试及改变选择的具体原因 | 先建立原办法失效的事件或可信取舍，不用窘迫表情直接换来妥协 |
| 胜利兑现 | 主角行动怎样产生结果，现场或后续怎样确认 | 补出观众能看见的变化，不只让旁人宣布主角赢了 |
| 通俗对白 | 逐场对照 SKILL.md 的“通俗对白”原文，核对大白话、直观利害、说话目的、是否替作者讲道理及人物表达差异 | 发现不符合原文规则的地方，先修改，再交付剧本 |
| 术语与利害 | 专业词、物证或专业判断影响人物选择时，观众能否在同一轮从对白或动作看懂要付多少钱、担什么风险、还能怎么选等具体利害 | 删掉与选择无关的行话。必要术语用当场一句口语或可见后果落地。原剧有意延后揭晓时，保持信息差，先交代人物眼下为什么这样做 |
| 承接与结尾 | 上批悬念有实际进展，新期待由本批后果产生 | 避免只推迟答案、突加电话来客或为凑批末仓促和解 |

定位后直接改正文，再读一遍修过的对白或动作，核对相邻轮次与前后场是否接得上。确认原先缺失的作用已经写进正文，再交付。格式、编号或材料读取检查通过，不代表以上项目通过；不以“整体符合”替代已经能定位的缺漏。

## 交付口径

最终交付按用户要求给正文、分析或对照，分析与对照给出证据和具体差异；执行中的进度简报按“执行过程可见”规则处理。保存成功才称已保存。格式范围检查不等于验证了“爆款”或“90%还原”，不作此类承诺。
