# 复刻工作流与写作指令

## 准备

先按 [project-records.md](project-records.md) 读取项目索引，核验参考来源版本、对应范围的分析与既有逐场映射。有效资料直接复用，只补缺或更新受影响部分，不因换会话重做拉片。

首次建立目标故事时，按 SKILL.md 的“首次创作方案确认”完成并交付大纲、主线、人物关系及世界观方案，待用户确认后再执行下文的正文写作与交付；已有确认方案或采用稿时直接复用。

执行中按 SKILL.md 的“执行过程可见”规则简报真实进度，最终正文可不附长表。

读取指定范围的实际参考正文或可读视频，以及对应人物、核心设定、主线总览、所需五场概括文件和推进表现手法。未分析时完成所需部分并保存到项目，不强制先展示整套拉片。按 [case-alignment.md](case-alignment.md) 读取与本批对应的完整原场片段，写前校准、写后纠偏。一比一范围的补充案例不得覆盖指定参考和保留要求；用户明确要求多剧融合或分段指定参考时，按同一共享案例规则明确每段来源、各剧贡献和允许的重构范围，不将融合结果冒称与所有来源均一比一。

明确本次场/集范围、需要对应的结构及用户指定的保留项。沿用原编号和叙事人称，正文按统一场记体交付，用户明确指定格式时按其要求执行。角色姓名、性别、身份和关系按新故事重新设计，具体设定遵守用户要求及目标稿已采用事实。前文已明确的信息直接复用。

## 逐场对应

使用 case-alignment.md 的共享对应模板记录“原场的戏剧作用与结构位置 → 新场用什么事件、交锋与结果实现”，具体包含推进阶段、交锋轮次、情绪积累和兑现、信息揭晓顺序、本场变化及结尾期待，并注明用户指定的保留项。按本批范围保存到项目的 `稿件资料/版本/写作对应/`，记录模式，同一文件从规划更新到写后结果；执行中简报实际来源和对应要点，最终正文可不附长表。

各行标明来源及版本，引用原剧已有分析和原文，允许多对多映射，不复制维护第二套源分析；冲突的设定、关系和事件按用户要求取舍或重构，不能将互不兼容的原剧事实并排拼入目标故事。

一比一范围保持场次对应、升级轮次与顺序、阶段回报和钩子落点，保留必要行动与反应在交锋中的作用；具体事件、动作与对白由新人物的处境推导。用户要求压缩、扩展、改结构或多剧融合时按其要求重排并保持因果，允许一对多或多对一，但不伪称场数相同。

把分析里的抽象评价还原为原场的行动与回应，再明确新场如何实现对应作用。不能只保留“被压价、离开、成功”等事件名称，却省略受阻、选择、代价和别人确认结果的过程。用户要求一比一时，不以重新创作为由打乱对应的结构、推进进度或情绪兑现位置。

先从新人物的关系、目标与利益设计冲突起因、对手筹码和主角应对，再落实道具、场景、证据与后果。新事件须凭自身因果成立，不能仅替换原场的人名、职业和道具；用户明确指定保留的部分按要求处理。

对应中说明本批事件怎样推进新故事的核心总线，以及如何对应参考的主线阶段与表现手法。涉及人物成长时，对应转变的铺垫、触发与兑现位置，具体选择由新人物的性格与经历支撑；不把原人物的性格和经历自动套入新角色。

## 写作指令

一比一复刻以该范围指定的实际原参考为结构主参考；明确多剧融合或分段复刻时，按索引“参考分工与融合约定”中的来源、保留项与重构范围执行。按以下要求输出指定范围的完整剧本正文：

1. 建立新主角的处境、能力、关系、利益矛盾及双方施压反击条件，使其能承载原场对应的戏剧作用。主要角色的性格、行为和表达习惯在新稿中持续成立；用户指定的保留项按要求沿用。
2. 一比一范围按原剧的结构顺序与推进层次逐场展开，新事件形成自身连续因果。写出谁发起行动、怎样回应、如何升级、本场改变什么、为何引出下一场，保持对应的交锋密度与推进进度。
3. 对应原场的观众情绪方向、积累过程、强度与兑现位置，在新故事中写出具体触发原因、铺垫、行动和反应；涉及翻盘与回报时不无意提前或拖延，不把其他情绪一律替换为解气。
4. 保留爽点的戏剧作用与兑现位置，由新人物的能力、选择、证据、关系变化或行动后果实现具体反击。不靠无依据的身份、大人物或事故跳过应有交锋。
5. 对应信息差的建立、揭晓顺序和悬念落点，具体信息与证据按新事件设计，人物按当时已知行动。已给出的答案正常兑现，后续承接保持对应。
6. 根据新人物的身份、脾气与当下目的重新组织对白，参考原场的口语程度、长短节奏和交锋方式，不逐句照抄或仅替换同义词。专业信息进入人物决策的那一轮，用口语或可见动作交代它影响的选择或后果，保持对应的揭晓位置。
7. 按新场景与新事件写具体动作和人物反应，完整实现原场对应的行动、应对与结果确认，不压成梗概，不用重复争吵凑篇幅。称呼、动机与行为须符合新设定。

## 回查与保存

按 checks.md 和案例对应片段同时检查结构贴合与新故事成立：核对交锋、节奏、强度、推进和钩子落点，再核对新人物的动机、事件因果及对白动作，修正遗漏、提前、弱化、结构偏离和整段照搬或仅换词换名的问题。用户明确指定的保留项不按照搬问题改掉。简报实际检查和修正；用户只要正文时最终可不附大段报告，不输出虚构效果评分；只有明确要求全程不说明时才省略进度，不输出冗长临时构思。

保留参考材料，新输出另存新稿。交付前保存本批分析、逐场映射与校准要点，关联实际新稿版本；多剧的长期分工与取舍更新到索引“参考分工与融合约定”，本批各来源的实际落实记录在同一份写作对应中。核对文件和索引的来源、覆盖及完成状态。本版本概括、人物和当前状态根据实际新稿更新；未采用范围不改变采用事实，明确采用后再更新采用记录与当前采用状态。参考剧后文不自动成为采用稿已发生事实。
