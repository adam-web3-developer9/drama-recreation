# 复刻工作流与写作指令

## 准备

先按 [project-records.md](project-records.md) 读取项目索引，核验参考来源版本、对应范围的分析与既有逐场映射。有效资料直接复用，只补缺或更新受影响部分，不因换会话重做拉片。

执行中按 SKILL.md 的“执行过程可见”规则简报真实进度，最终正文可不附长表。

读取指定范围的实际参考正文或可读视频，以及对应人物、核心设定、主线总览、所需五场概括文件和推进表现手法。未分析时完成所需部分并保存到项目，不强制先展示整套拉片。按 [case-alignment.md](case-alignment.md) 读取与本批对应的完整原场片段，写前校准、写后纠偏。一比一范围的补充案例不得覆盖指定参考和保留要求；用户明确要求多剧融合或分段指定参考时，按同一共享案例规则明确每段来源、各剧贡献和允许的重构范围，不将融合结果冒称与所有来源均一比一。

明确本次场/集范围、必须保留项、获准修改项。沿用原编号和叙事人称，正文按统一场记体交付，用户明确指定格式时按其要求执行。保留未要求更改的人名、职业、关系和题材。前文已明确的信息直接复用。

## 逐场对应

使用 case-alignment.md 的共享对应模板记录参考场与新场，具体包含核心条件与交锋、情绪积累和兑现、信息/证据顺序、本场变化及结尾期待、获准变更。按模式、本批范围和新稿版本保存到项目的“写作对应”目录；执行中简报实际来源和对应要点，最终正文可不附长表。

各行标明来源及版本，引用原剧已有分析和原文，允许多对多映射，不复制维护第二套源分析；冲突的设定、关系和事件按用户要求取舍或重构，不能将互不兼容的原剧事实并排拼入目标故事。

一比一范围保持升级轮次、顺序、阶段回报和必要动作反应。用户要求压缩、扩展、改结构或多剧融合时按其要求重排并保持因果，允许一对多或多对一，但不伪称场数相同。

把分析里的抽象评价还原为原场的行动与回应，落实到对照表。不能只保留“被压价、离开、成功”等事件名称，却省略受阻、选择、代价和别人确认结果的过程。用户要求一比一时，不以自行优化为由改掉明确要求保留的原作安排。

获准替换的角色、道具、场景仍需承担对应关系、证据或行动作用。适配称呼与动机，维持核心设定与获准变更的一致性。

对应中说明本批事件怎样延续指定参考的核心总线、体现中心及主导表现手法。人物成长按原场过程保留；原作疑似人设漂移先标明，是否调整服从用户的保留与修改要求，不以优化为由擅改一比一范围。

## 写作指令

一比一复刻以该范围指定的实际原参考为唯一主参考；明确多剧融合或分段复刻时，按索引“参考分工与融合约定”中的来源、保留项与重构范围执行。以下要求在相应保留范围内适用，输出指定范围的完整剧本正文：

1. 保留主角处境、能力、关系、利益矛盾，以及双方施压反击条件；主要角色的性格、行为和表达习惯落实到原场对应的选择、对白和动作，不能只保留身份与事件却换了人物做事方式。用户明确修改部分按要求适配。
2. 一比一范围按原剧事件顺序与因果逐场展开；获准融合的范围按明确的取舍重构统一因果。写出谁发起行动、怎样回应、如何升级、本场改变什么、为何引出下一场。
3. 保留原场使观众产生喜悦、愤怒、悲伤、紧张、温暖等感受的具体原因与变化，按实际情节写足铺垫、行动和反应；涉及翻盘与回报时不无意提前或拖延，不把其他情绪一律替换为解气。
4. 保留爽点实现方式，用能力、选择、证据、关系变化或行动后果形成对应反击。不新增无依据的身份、大人物或事故替代原有过程。
5. 保留信息证据顺序，人物按当时已知行动。已给出的答案正常兑现，悬念及后续承接保持对应。
6. 参考台词口语程度、长短和交锋方式，每句话服务当下目的。专业信息进入人物决策的那一轮，用口语或可见动作交代它影响的选择或后果，保留原剧设定的揭晓顺序。
7. 保留有效动作与人物反应，完整写交锋，不压成梗概，不用重复争吵凑篇幅。获准变更同步到称呼、动机与行为。

## 回查与保存

按 checks.md 和案例对应片段检查实际新稿的交锋、对白动作与结果，局部修正遗漏、提前、弱化、顺序偏离与未经允许新增，并简报实际检查和修正。用户只要正文时最终可不附大段报告，不输出虚构效果评分；只有明确要求全程不说明时才省略进度，不输出冗长临时构思。

保留参考材料，新输出另存新稿。交付前保存本批分析、逐场映射与校准要点，关联实际新稿版本；多剧的长期分工与取舍更新到索引“参考分工与融合约定”，本批各来源的实际落实记录在同一份写作对应中。核对文件和索引的来源、覆盖及完成状态。未采用新稿的对应记录不改变采用稿状态。明确采用后建立采用稿自己的概括、人物和当前状态。参考剧后文不自动成为采用稿已发生事实。
