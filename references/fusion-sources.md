# 共享案例规则的方法来源

本 Skill 的多来源选取、融合与校准统一维护在 [case-alignment.md](case-alignment.md)。下表用于来源追溯，不是第二套执行流程。参考 AIStudio 已下载的原始快照后，按本 Skill 的文本任务和项目文件约定转化方法；不依赖本机 AIStudio 路径、原包安装或脚本。

保留本项目的用户数量、编号、正文格式、采用机制和文件存储约定。不引入原包的阶段确认锁、固定评分权重、镜头/时长配额、强制联网采风或其他与当前文本任务无关的执行步骤。只有实际读取的来源范围可以支撑分析，方法借鉴不等于已验证作品效果。
